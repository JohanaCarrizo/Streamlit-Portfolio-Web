# 📸 Portfolio Web - Fotógrafo Profesional (Streamlit)

Este proyecto es un portfolio web interactivo y minimalista desarrollado con **Streamlit**, diseñado para mostrar trabajos de fotografía, trayectoria profesional y facilitar el contacto con clientes. 

El objetivo principal de este repositorio es servir como base de estudio, práctica y experimentación de la aplicación de **Streamlit**.

---

## ✨ Características Principales

- **Diseño Moderno & Modo Oscuro:** Interfaz limpia inspirada en estilos tipo *Glassmorphism*, con paletas de colores optimizadas (`#0f172a` y `#1e293b`) para una experiencia visual elegante.
- **Sección Hero Interactiva:** Pantalla de bienvenida con imagen de fondo superpuesta y efectos visuales personalizados mediante marcos de contenido.
- **Navegación Fluida:** Menú lateral dinámico usando *multipage* para alternar de forma limpia entre las diferentes secciones sin recargar la página completa.
- **Adaptabilidad y Estilos CSS:** Ocultación de elementos nativos de Streamlit (como el menú superior y el footer por defecto) para lograr el aspecto de una aplicación web independiente.
